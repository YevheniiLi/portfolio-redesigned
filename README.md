# Yevhenii Lymarenko — Portfolio

A lightweight React/Vite portfolio for a React-focused Front-End Developer based in Girona, Spain.

## Run locally

```bash
npm install
npm run dev
```

## Production checks

```bash
npm run lint
npm run build
```

## Content

The portfolio's copy, project details, skills, experience, and profile links live in [`src/data/portfolio.js`](src/data/portfolio.js). Update that file when adding a project or changing contact details.

Project imagery is served from `public/images/`. The site avoids runtime image libraries and third-party fonts to keep the experience fast and self-contained.
